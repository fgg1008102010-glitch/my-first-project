# My First GitHub Project

## Мен туралы

Менің атым Нурислам. Мен бағдарламалық қамтамасыз ету бағыты бойынша білім алып жатырмын.

## Жоба туралы

Бұл менің GitHub-тағы алғашқы жеке жобам. Бұл жоба GitHub платформасымен жұмыс істеуді және Git жүйесінің негізгі мүмкіндіктерін үйрену үшін жасалды.

## Мақсаты

- GitHub-пен жұмыс істеуді үйрену
- Репозиторий құру
- README.md файлын пайдалану
- Commit жасау
- Өзгерістер тарихын бақылау
